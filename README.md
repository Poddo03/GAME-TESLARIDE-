# Tesla Ride

## Game Description

**Tesla Ride** is a 2D driving simulation and action game built using the **iGraphics** library in C++. The player controls an electric rickshaw navigating through the busy streets of Dhaka, dodging traffic, collecting coins, and completing passenger trips across different destinations before time or lives run out.

## Features
- 3 playable levels: Station - Basabo, Station - Moghbazar, and Station - Aust.
- Interactive comic-style bargaining story between passenger and rickshaw driver.
- Garage system to unlock and equip upgraded rickshaws (Classic Blue, Deluxe Green , Super Red ).
- Power-ups including an Energy Shield (15s invulnerability) and bullet shooting mechanic in Level 3.
- Coin collection economy with persistent file save/load (`userdata.txt`).
- Dynamic background music, traffic horns, and sound effects.

## Project Details

IDE: Visual Studio 2013
Language: C, C++

## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **iGraphics Library** (included in this repository)

Open the project in Visual Studio 2013
- Open Visual Studio 2013.
- Go to File → Open → Project/Solution.
- Locate and select the `Tesla RIde.sln` file from the cloned repository.
- Click Build → Build Solution.
- Run the program by clicking Debug → Start Without Debugging.


## How to Play

### **Controls**

| Action | Key / Input |
 
| **Move Left** | `A` or `←` (Left Arrow) |
| **Move Right** | `D` or `→` (Right Arrow) |
| **Accelerate** | `W` or `↑` (Up Arrow) |
| **Brake / Slow Down** | `S` or `↓` (Down Arrow) |
| **Shoot (Level 3)** | `F` or `Space` or `↑` (Double Up Arrow)|
| **Activate Shield** | Click Shield Icon |
| **Advance Dialog / Select** | Mouse Click |
| **Garage** | Mouse Click |
| **Menu / Retry** | `M` (Menu), `R` (Retry) |


### **Game Rules**

- Reach the destination station before time runs out or lives are lost.
- Avoid collisions with oncoming buses, cars, and road hazards.
- Collect coins on the road to buy upgrades in the Garage and unlock new stages.
- Level 1 has a countdown timer; Level 2 gives you 3 lives; Level 3 gives you 5 lives and bullet shooting mechanics.
- Activate the Energy Shield to protect against obstacle damage.
